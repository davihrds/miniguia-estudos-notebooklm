# miniguia-estudos-notebooklm
Este repositório apresenta um estudo sobre a vida de Leonardo da Vinci, destacando sua trajetória no Renascimento e suas contribuições para a arte, ciência e tecnologia. O objetivo é compreender seu legado e organizar o aprendizado utilizando ferramentas de IA para análise, síntese e revisão do conteúdo.
